# 共享 MMVQ 几何单例误差证据（Qwen2.5 0.5B，Graph off）

这份报告使用最终代码重新运行的单例仿真；native 中位数沿用已有 2026-10-08 记录，没有把旧 native 记录伪装成新测量。

| 指标 | 新仿真 | native 中位数（复用） | 有符号误差 | 绝对误差 | 相比旧仿真绝对误差变化 |
|---|---:|---:|---:|---:|---:|
| TTFT | 7.146966 ms | 13.805000 ms | -48.23% | 48.23% | +6.49 个百分点 |
| TPOT | 1.425394 ms | 3.224866 ms | -55.80% | 55.80% | +0.34 个百分点 |
| E2E | 188.171997 ms | 423.387000 ms | -55.56% | 55.56% | +0.54 个百分点 |

编译覆盖摘要：

- GPU GEMM 共 21632 个去重任务，其中 10796 个进入 `source_rule_geometry`，10836 个保持未覆盖。已覆盖格式为 Q4_K=1524、Q5_0=6096、Q6_K=1524、Q8_0=1652，本次均为 M=1；M=512 仍回退 MMQ。
- activation conversion 任务为 15496 个，按同一 input buffer、M、K、格式共享 producer；没有跨 input buffer 或跨物理权重共享。
- 这条路径没有 native dispatch 证明、没有实测速率、没有写入拟合参数；因此当前结果证明“新逻辑已启用”，不证明“端到端精度已改善”。

当前单例仍明显低估 native：TTFT、TPOT、E2E 的绝对误差分别为 48.23%、55.80%、55.56%。相比旧仿真，误差分别变化 +6.49、+0.34、+0.54 个百分点；剩余差异应继续从 launch、packed transform、kernel 速率和运行时语义拆分，不能用校准常数掩盖。
